# Public source scope

The 2026-11-01 instructions replace earlier commercial-theme and desktop-plugin marketplace plans.

- Free and open source; project code MIT, dependencies retain their licenses.
- Windows x64 only. Claude Desktop uses MCPB; Claude Code and OpenAI Codex use the portable binary through local stdio MCP.
- One shared, explicitly selected `THOUGHTS_HOME`; legacy libraries remain unchanged unless separately migrated.
- No paid themes, subscriptions, payments, cloud services, remote MCP, mobile or browser extension.
- No ordinary ChatGPT web plugin target. No account or bundled AI.
- Optional sponsorship is configured with the owner's Base mainnet address and a locally generated address-only QR. No wallet connection, private-key collection, payment processing, required donation, preset asset or amount.

The public export omits private legacy plugin metadata/installers, deferred platform prototypes, original input archives and historical machine-specific reports. Existing private Git history remains unchanged. The public source inventory is in [PUBLIC_SOURCE_FILES.md](PUBLIC_SOURCE_FILES.md). [preview.21](UNSIGNED_PREVIEW.md) is publicly available as an explicitly authorized unsigned prerelease. Future source snapshots, new releases and signed stable distribution still require their own review and authorization.
