## 普通人怎样安装

正式发行后，在 GitHub Releases 下载 `thoughts-<版本>-windows-amd64-setup.exe`，
核对校验值与发布者签名后，**双击 → 安装 → 打开 Thoughts**。
无需 Go、Node、Python、Docker、Thoughts 账号或管理员权限。
安装程序自动选择系统语言，提供与应用一致的八种语言。

程序入口在当前用户的本地 Programs 目录；资料仍在 Windows 用户的 Thoughts 目录。
桌面和开始菜单快捷方式按实现绑定到指定共享核心，以保留自定义主目录；
最终版本的快捷方式端到端测试因 SAC 拦截尚未完成。
安装包不自动安装、接管或修改 AI 客户端；MCP 接入另选对应客户端步骤。
完整步骤见 [安装说明](../INSTALL.md)。

重装沿用原资料库，通过哈希校验和现有运行时机制更新。升级前保留旧核心与运行时指针备份；
有未保存编辑时会拒绝切换。软件回退不会恢复笔记正文，笔记仍需单独备份。

卸载只移除安装器管理的程序入口、快捷方式与卸载登记。
**共享核心、笔记、图片和配置会保留**，供用户及其他 MCP 客户端继续使用；
不会强制结束其他客户端共用的服务，也不会递归清空用户资料库。
没有添加自动启动或网络自动更新。
