## Historical records / 历史记录

该阶段最终本地候选：`0.3.0-preview.4`。只修改本地文件，未提交或推送，未替换已安装客户端，未改动用户真实资料库。

## 改动

- 设置中的主题区域仅保留“导入主题”和必要的导入错误提示；移除外观标题、说明、Classic 卡片和示例下载链接。导入后继续自动应用有效的浅色主题。
- 每篇笔记拥有独立标签；再次点击复用原标签。可分别关闭，关闭当前页回到相邻标签；改名或移动后更新路径。浏览器缓存仅保存标签路径和导航状态，不保存笔记正文。
- 沿用既有保存与 SHA256 冲突保护：切换或关闭当前笔记前保存；保存失败、存在外部冲突或图片上传时拒绝离开，不丢草稿。
- 编辑／预览入口移到固定顶部右侧。打开已有笔记和刷新网页仍默认预览。
- 正文图片统一使用最大 360 × 240 px 的预览框，按原比例完整显示，不裁切、不放大小图。点击可看大图；原图片文件不重采样、不覆盖。
- 标签多时只在标签栏内横向滚动；窗口缩窄或侧栏改变宽度后自动确保当前标签及关闭按钮可见。

## 测试环境与真实文件

Windows 11 x64 开发机，Codex 内置 Chromium 浏览器。桌面 1440 × 900，窄窗口 900 × 720，结束后恢复实际浏览器尺寸。使用编译后 Go 程序内嵌的网页，未使用 Vite 开发服务器代替最终运行。

隔离库在忽略的 `.artifacts/preview3-mcp-acceptance/home/library`，名称保留中间版编号以核对原文件。待办、想法及另外五篇测试笔记均通过正式 CLI 创建；横图、竖图和小图通过正式本地图片接口上传。界面读取这些真实文件，不硬编码生产假笔记。

## 安全与范围

最终 .4 exe 仍为 **NotSigned**，SHA256 为 `8c2a7dd55cf67d64c3bebee51ef9d5646c5811a8345060e78dd21c827686c96b`。本机 SAC On；Defender 对该 exe 的扫描完成，匹配威胁记录 0。两包内部 exe 一致，实际运行服务也已通过只读证据核对。

这不是干净 Windows、Claude Desktop 导入、Claude Code/Codex 实际宿主工具调用验收。**M0 仍未通过。** 没有修改系统保护、安装证书或签名。此前网络受限沙箱中的本地 API 请求返回套接字权限错误，获准执行同一个隔离请求后成功；没有因此关闭防火墙或其他安全功能。
